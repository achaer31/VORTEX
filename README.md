# VORTEX

XAUUSD research workspace: historical data exporter, deterministic backtester, and a personal research dashboard.

This repository begins with the work completed on 14 September 2026. Earlier local changes are documented retrospectively; this is not a reconstruction of an existing Git history.

Current research: 32 historical scenarios with an initial simulated balance of USD 50 produced zero trades because the minimum lot exceeded the configured risk budgets. This is not evidence of profitability. No broker order execution is included.

Source, tests, reproducibility notes, and dashboard are being organized in the next commits. Credentials, account identifiers, and remote-access configuration do not belong in this repository.
